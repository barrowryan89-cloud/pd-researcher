# CONTENT_WORKFLOW.md - Publishing Protocol

## Rule: Nothing Goes Live Without Human Approval

### Workflow
1. **Draft** → Create content
2. **Submit** → Send to approval channel with approve/reject buttons
3. **Human Review** → Ryan decides
4. **Execute** → If approved, publish. If rejected, discard.

### No Autonomous Publishing
- I draft. Ryan approves. Then I ship.
- Exception: Farming scripts (pre-approved), monitoring (no public impact)

### Approval Queue Location
Track pending approvals in:
- `memory/pending_approvals.md`
- Or daily log with [PENDING] tag
