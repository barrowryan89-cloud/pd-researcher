Popular Tools in Detail

1. Git Analyzer (git_analyzer.py)

Deep-dive into any Git repository. Get contributor stats, commit frequency, code churn metrics, and language breakdowns. Perfect for understanding project health and team productivity.

python tools/git_analyzer.py /path/to/repo --format json

2. CSV to JSON Converter (csv_to_json.py)

Convert CSV files to JSON with support for nested objects, type inference, and custom delimiters. Handles large files efficiently with streaming.

3. Password Generator (password_gen.py)

Generate cryptographically secure passwords with customizable length, character sets, and exclusion rules. No more weak passwords.

4. Regex Tester & Debugger (regex_tester.py)

Test, debug, and explain regular expressions locally. Match highlighting, group extraction, pattern explanation, and 10+ common regex patterns built-in. No online service needed — works entirely offline.

python tools/regex_tester.py "\d{3}-\d{4}" "Call 555-1234" python tools/regex_tester.py -e "^[a-z]+$" # Explain pattern python tools/regex_tester.py -l # List common patterns

Frequently Asked Questions

Do I need to install Python packages?

No. Every tool uses only Python's standard library. No pip install, no virtual environments, no dependency hell.

Can I modify and redistribute these tools?

Yes. All tools are open source (MIT license). Use them in personal projects, commercial work, or redistribute them. No attribution required (though it's appreciated).

What Python version do I need?

Python 3.6 or higher. All tools are tested on Python 3.8+ but should work on any modern Python 3 installation.

Are these tools cross-platform?

Yes. They work on Linux, macOS, and Windows. No platform-specific code or dependencies.

How do I get help with a specific tool?

Every tool has built-in help. Run python toolname.py --help to see usage instructions, examples, and available options.
