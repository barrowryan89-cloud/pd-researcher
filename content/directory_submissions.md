# Directory Submission Plan

## 🎯 Top High-Value Targets

We need to be where developers hang out.

### 1. Product Hunt
*   **Title:** PD Researcher CLI Suite
*   **Tagline:** 60+ Open Source Developer Tools in one package.
*   **Category:** Developer Tools, Open Source, Productivity.
*   **First Comment:** "Hi Hunters! 👋 I was tired of rewriting the same scripts. So I bundled my top 60 utilities into one repo. It handles everything from AWS management to local DB cleaning. Free & Open Source."

### 2. Hacker News (Show HN)
*   **Title:** `Show HN: I built 60+ CLI tools to replace my paid SaaS subscriptions`
*   **Time:** Submit between 8:00 AM - 10:00 AM ET (Peak traffic).
*   **Strategy:** Be humble, technical, and responsive. Post the direct GitHub link, not the landing page (HN users prefer code).

### 3. Reddit
*   **Subreddits:**
    *   `r/commandline` (Focus on the tech stack/implementation)
    *   `r/webdev` (Focus on the "Zero Dollar Stack")
    *   `r/devops` (Focus on the cloud/docker tools)
    *   `r/opensource`
*   **Template:** See `social_drafts.md` (Thread 3).

### 4. Dev.to / Hashnode
*   **Title:** "How I automated my entire workflow with 60 custom CLI tools"
*   **Tags:** `#productivity`, `#opensource`, `#cli`, `#webdev`
*   **Content:** Write a tutorial showing how to use *just one* of the tools effectively, then link the whole suite at the end.

### 5. Awesome Lists (GitHub)
*   **Target:** `awesome-cli`
*   **Target:** `awesome-shell`
*   **Target:** `awesome-productivity`
*   **Action:** Submit a Pull Request to add `pd-researcher` to these lists.
*   **Format:** `- [PD Researcher](https://github.com/...) - A collection of 60+ productivity CLI tools.`

### 6. Lobste.rs
*   **Strict Moderation:** Only post if you have an invite and a high-quality technical blog post accompanying the release. Do not just drop a link.

### 7. BetaList / 10Words
*   **Status:** Lower priority, but good for SEO backlinks.
*   **Description:** "Open source developer productivity suite."

## 📅 Submission Schedule (Suggested)
- **Day 1:** Hacker News (Morning) + Reddit (Lunch)
- **Day 2:** Product Hunt (12:01 AM PT)
- **Day 3:** Dev.to Article + Medium Import
- **Day 4:** Awesome List PRs
