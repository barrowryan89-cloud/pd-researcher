# Solana Airdrop Farming Checklist

**Quick-start checklist for farming Solana airdrops**

## Pre-Farming Setup
- [ ] Buy 1 SOL from exchange
- [ ] Install Phantom wallet (or Solflare)
- [ ] Create 4 separate wallets for farming
- [ ] Send 0.25 SOL to each wallet
- [ ] Bookmark protocol websites

## Daily Tasks (5 min)
- [ ] Check MarginFi health factor
- [ ] Check Kamino vault positions  
- [ ] Review any notifications

## Weekly Tasks (15 min)
- [ ] Execute Jupiter swap
- [ ] Check Drift positions
- [ ] Review points accrual on all protocols
- [ ] Check for new protocol launches

## Protocol-Specific Actions

### MarginFi
- [ ] Deposit SOL or USDC
- [ ] Monitor health factor (keep > 1.2)
- [ ] Borrow 50% of deposit (optional, boosts points)

### Kamino  
- [ ] Deposit into JitoSOL vault
- [ ] Check APY vs points tradeoff
- [ ] Consider leverage (multiply feature)

### Drift
- [ ] Deposit collateral
- [ ] Make 2-3 small perp trades
- [ ] Close positions before funding

### Jupiter
- [ ] Swap SOL ↔ USDC
- [ ] Set limit orders
- [ ] Use DCA for recurring swaps

## Safety Checks
- [ ] Never share private keys
- [ ] Use different wallets for different protocols
- [ ] Don't deposit more than you can afford to lose
- [ ] Monitor for smart contract hacks/exploits

## Tracking
- [ ] Log all transactions
- [ ] Screenshot points dashboards weekly
- [ ] Track which wallet farms which protocol
- [ ] Note any protocol announcements

## Expected Timeline
- **Month 1:** Set up, begin farming
- **Month 3:** Points accumulate, protocols announce tokens
- **Month 6:** Airdrops begin, claim and sell

---

*Save this checklist and check off items as you complete them.*
