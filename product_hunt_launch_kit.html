    Launch Day Assets

    #### 1. Tagline (60 chars max) ``` 98 open-source CLI tools. Zero dependencies. Zero installation. ```

    #### 2. Description (260 chars max) ``` A collection of 98 single-file CLI utilities for developers. From JSON validators to git helpers to deployment scripts — all free, open source, and ready to use. No npm install. No docker. Just copy, paste, and ship faster. ```

    #### 3. Thumbnail/Gallery Images

    Required Sizes:

  • Thumbnail: 240x240px (logo/icon)
  • Gallery: 1270x760px (up to 8 images)

    Image Concepts: 1. Hero Image: Terminal screenshot showing 3-4 tools in action 2. Feature Grid: Visual grid of tool categories (DevOps, Git, JSON, etc.) 3. Code Preview: Clean code snippet showing simple usage 4. Stats Card: "98 tools | 0 dependencies | 100% free" 5. Social Proof: GitHub stars + contributor count (once established)

    #### 4. Maker Comment (First Comment) ``` Hey Product Hunt! 👋

    I built this because I was tired of:

  • Installing 500MB npm packages for simple tasks
  • Paying $10/mo for CLI tools that should be free
  • Context switching away from my terminal

    So I created 98 single-file CLI utilities. Each one: ✅ Does ONE thing well ✅ Has zero dependencies ✅ Works immediately (just curl & run) ✅ Is completely free and open source

    My most-used tools:

  • `json-fix` - Validate/beautify JSON without leaving terminal
  • `port-kill` - Kill processes by port (saves me 5 min daily)
  • `epoch-now` - Quick timestamp conversions
  • `git-todo` - Task tracking embedded in git

    Everything is at https://github.com/barrowryan89-cloud/pd-researcher

    I'm actively adding more based on what the community needs. What repetitive dev task should I build a tool for next? 🛠️ ```
