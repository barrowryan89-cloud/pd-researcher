How to Use This Sheet

1. Log instantly: The moment you click “Submit” (or send an email), add the UTC timestamp, your name/handle, and any confirmation details. 2. Attach receipts: Save screenshots or PDF confirmations inside `assets/receipts/` and reference the filename in the Proof column so moderators see we’re organized. 3. Sync other docs:* After logging here, update `content/directory_status_board.md` *and append the receipt to `content/distribution_receipts.md` for the global log. 4. Automate follow-ups: Each row references the cadence from `content/directory_followup_schedule.md`. Set calendar reminders or write TODOs inside the Notes column of the status board so nothing slips. 5. Archive weekly: Once a directory is approved (or closed), move the historic row to `content/directory_submission_receipts_archive.md` (create if missing) to keep this file short and actionable.

With this tracker, anyone can answer “Did we already submit to X?” or “When’s the next follow-up?” in under 5 seconds.
