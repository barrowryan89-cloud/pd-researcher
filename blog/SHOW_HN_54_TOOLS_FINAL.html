POST BODY:

I got tired of leaving my terminal to validate JSON, convert timestamps, or check if a website was up. Each context switch killed my flow state.

So I built 54 single-purpose CLI tools. Each one:

  • Zero dependencies (stdlib only)
  • Single file (read the code in 30 seconds)
  • MIT licensed (truly free)
  • Works offline

    The tools:

    Data & Security (12): JSON formatter, base64 tool, password generator, hash generator, JWT decoder, UUID generator, timestamp converter

    Network & Web (12): Port scanner, URL checker, website monitor, IP info, HTTP requester, API tester, webhook tester, SSL cert inspector

    System & DevOps (12): Memory monitor, process monitor, log analyzer, directory size, duplicate finder, system info

    Productivity (18): CSV processor, diff tool, regex tester, cron parser, random generator, line counter, markdown converter, and more

    The philosophy:

    If it needs `pip install`, it doesn't belong here. Each tool is copy-paste-run. Battle-tested in production workflows.

    ```bash curl -fsSL https://barrowryan89-cloud.github.io/pd-researcher/install.sh | bash ```
