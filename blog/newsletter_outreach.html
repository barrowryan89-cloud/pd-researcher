    Outreach Templates

    Template 1: Console.dev Style

    ``` Subject: 98 open-source CLI tools with zero dependencies

    Hi Console team,

    I built a collection of 98 single-file CLI utilities for developers — all open source, zero dependencies, ready to use.

    The tools cover:

  • Git workflows (git-todo, git-stats, git-cleanup)
  • JSON/XML processing (json-fix, json-diff, xml-pretty)
  • DevOps (cloud-audit, log-watch, deploy-hook)
  • Productivity (focus-mode, standup-gen, pomodoro)

    Each tool is intentionally simple (single file, no dependencies) so developers can audit, modify, and trust the code.

    Repo: https://github.com/barrowryan89-cloud/pd-researcher Landing page: https://barrowryan89-cloud.github.io/pd-researcher/

    I think your audience would find value in the collection. Happy to answer any questions or provide more details.

    Best, Ryan Barrow ```

    Template 2: TLDR Style

    ``` Subject: Tool submission: 98 open-source CLI utilities

    Hi TLDR team,

    Quick tool submission for your newsletter:

    What: 98 open-source CLI tools for developers Hook: Zero dependencies, single files, copy-paste ready Use case: Replace SaaS subscriptions with local utilities Link: https://github.com/barrowryan89-cloud/pd-researcher

    Most popular tools so far:

  • json-fix (validate/beautify JSON)
  • port-kill (kill processes by port)
  • git-todo (task tracking in git)
  • epoch-now (timestamp conversions)

    Built this to solve my own workflow friction. Open source and free forever.

    Let me know if you need any other info.

    Ryan ```

    Template 3: Indie Hackers Style

    ``` Subject: Show IH: 98 CLI tools built in 48 hours

    Hi IH team,

    I wanted to share a project with your community:

    The Project: A collection of 98 CLI tools I built in 48 hours The Why: I was paying $200+/month for SaaS tools that should've been simple scripts The Result: Open-sourced everything. Zero dependencies. Free forever.

    Most interesting part: The "boring" tools get the most use. A simple port-killer saves me 5 minutes of frustration daily. That compounds.

    Links:

  • GitHub: https://github.com/barrowryan89-cloud/pd-researcher
  • Landing page: https://barrowryan89-cloud.github.io/pd-researcher/

    Happy to share the full breakdown of what I learned if helpful.

    Ryan Barrow ```
