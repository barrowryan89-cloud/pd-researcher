**Value:** One command, all formats, smart format detection

- Outputs: epoch, ISO 8601, RFC 2822, human-readable, relative time
- `timestamp now` for current time
- `--format` flag for specific output
- `--parse` to just detect format without converting

**Examples:**

## 🚀 Shipped: Tool #58 — `json_diff`

**What:** JSON comparison utility — like git diff for JSON files  
**Why:** Developers constantly compare config files, API responses, data exports  
**Value:** Precise structural diff with color coding, path tracking, CI-friendly exit codes

**Features:**
- Deep recursive comparison of any JSON structure
- Color-coded output: added (green), removed (red), modified (yellow)
- Full path tracking (e.g., `users[3].profile.name`)
- Type change detection (string → number, etc.)
- Array length change detection
- Stdin support for piping (`cat file.json | json_diff - other.json`)
- `--summary` flag for CI/CD (exit code 1 if differences found)
- `--no-color` for clean output redirection

**Examples:**
```bash
json_diff config.prod.json config.dev.json
json_diff old_data.json new_data.json --summary && echo "No changes"
curl api.com/data | json_diff - cached.json
```
