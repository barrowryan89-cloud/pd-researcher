# PD Researcher Agent Template

A lightweight, powerful research agent that aggregates multiple sources and returns structured, actionable intelligence.

## What You Get
- Pre-configured research agent (drop into OpenClaw/skills/)
- Multi-source aggregation (web, news, docs)
- Structured JSON output
- Error handling & retry logic
- Full setup instructions (2 min read)
- Working example + test cases

## Use Cases
- Market research
- Competitor analysis
- Content research
- Due diligence
- Trend monitoring

## Setup
1. Download and unzip
2. Copy `research-pro/` folder to `~/.openclaw/skills/`
3. Restart OpenClaw or reload skills
4. Type: "Research [topic]"

## Requirements
- OpenClaw installed
- Internet connection
- No API keys required
