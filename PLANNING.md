# PLANNING.md - Execution Protocol

## Rule: "Write it down, no mental notes"
Mental notes don't survive sessions. Files do.

## Plan Mode (3+ Steps)
For anything requiring 3 or more steps:
1. **Write the plan first** (list steps)
2. **Get confirmation** (if uncertain)
3. **Execute**
4. **Stop and re-plan** if assumptions break

## Definition of Done
Every task needs verification:
- **Code:** Commit hash or test output
- **Deploy:** Live URL or `curl` check
- **Transaction:** Tx hash or confirmation
- **No vibes.** Proof or it didn't happen.

## Queue Discipline
Never silently drop a message.
- If I can't handle it now → Acknowledge + Log it + Set reminder
- If blocked → Say why + Propose workaround
